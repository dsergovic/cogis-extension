Cogis

Search your own AI conversation history — ChatGPT, Claude, Gemini, Perplexity and Grok — from one box, and jump straight back into the original chat.

Install from GitHub View the source

A Chrome extension. Free and open source. Not on the Chrome Web Store yet.

How it works

  1. Stay signed in to the AI assistants you use, in the same Chrome profile. Cogis uses the sessions you already have — no accounts, no API keys.
  2. Click the Cogis icon in your toolbar. A search window opens, centered over the page you're on.
  3. Type and press Enter. Each assistant is searched live, in parallel. Results come back grouped by assistant, and every one is a link into the original conversation.

It's a launcher, not a knowledge base: you get a title, a date and a link — never a copy of the conversation.

Five assistants, one search

  • ChatGPT
  • Claude
  • Gemini
  • Perplexity
  • Grok

All five are searched full-text, so a result can match on something said inside a conversation, not just its title. You can switch any of them off in Settings.

Sharper searches

"exact phrase"
Put a phrase in quotes to match it exactly. None of the assistants' own searches honor quotes, so Cogis checks the phrase itself. Matches it can't confirm are kept but tucked under Unverified matches.
Filler words don't count on their own
Words like vs, the and for can't carry a match by themselves, so devops vs github won't turn up every chat that happens to compare two other things.

Private by design

  • No server. Cogis has no backend. Your query goes only to the assistants you already use, from your own browser.
  • Nothing stored. No caching and no search history — every search runs fresh, and nothing about it is written anywhere.
  • No conversation content. Only a title, a date and a link ever reach your results. Message bodies are never stored, indexed or shown.
  • No tracking. No analytics, no telemetry, no phoning home.
  • No credentials. It never asks for a password or key, and never stores a session.

The full privacy and terms-of-service posture is in NOTICE.

Install

Until Cogis is on the Chrome Web Store, load it as an unpacked extension. It takes about a minute:

  1. Download or clone the repository.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and choose the extension folder.
  4. Pin Cogis — AI Search to your toolbar and click it.
